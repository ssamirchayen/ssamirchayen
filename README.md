## Projetos em destaque

### Atlas — assistente e automação

Plataforma modular em Python para explorar assistência por IA, memória,
interação por voz, automação e integração com sistemas empresariais.

- Integração com modelos locais por meio do Ollama.
- Componentes de memória, voz, visão e execução de tarefas.
- Fluxos de automação e integração com o Nexyra CRM.
- Copiloto, ferramentas de validação e testes automatizados.

O projeto prioriza execução local quando aplicável. Integrações externas podem
exigir rede, credenciais e infraestrutura adicional.

[**Ver o CRM + Atlas →**](https://github.com/ssamirchayen/nexyra-crm-atlas)

## Radiologia computacional: projeto experimental

No Atlas, desenvolvo um módulo de pesquisa sobre **reconstrução geométrica 3D
estimada a partir de múltiplas projeções**, com importação de imagens,
anotações manuais, geometria fornecida, visualização e exportação de malhas.

O trabalho atual utiliza laboratórios sintéticos para testar o fluxo técnico.
**Não equivale a tomografia e não possui validação clínica.** Dados reais
autorizados, avaliação independente e reconstrução neural permanecem como
frentes de desenvolvimento.
